# URL Shortener Service

Сервис для сокращения ссылок с использованием предварительно подготовленных хешей, локального и распределённого кеширования, а также механизма повторного использования коротких кодов.

---

## Стек технологий

- Java 17  
- Spring Boot 3.5.4  
- PostgreSQL, Hibernate/JPA, JDBC  
- Liquibase  
- Redis  
- MapStruct, Lombok  
- REST API, OpenAPI/Swagger  

---

## Функциональность

### Создание короткой ссылки  
`GET /api/v1/url`

- Контроллер вызывает `UrlServiceImpl.createShortUrl(dto)`.  
- Из локального кеша (`HashCacheImpl`) выбирается заранее подготовленный хеш.  
- Данные сохраняются в PostgreSQL и Redis.  
- Пользователю возвращается короткий URL.

### Переход по короткой ссылке  
`GET /api/v1/{hash}`

- Оригинальный URL извлекается из Redis.  
- Если кеш не содержит запись — выполняется поиск в PostgreSQL по индексу `hash`.  
- Результат кешируется в Redis.

## Основные компоненты

### CleanerScheduler  
Периодически удаляет устаревшие записи и возвращает освободившиеся хеши в хранилище свободных хешей для повторного использования.

### HashCacheImpl  
Локальный кеш хешей:  
- при старте загружает пакет свободных хешей из БД;  
- хранит их в очереди;  
- при снижении количества запускает генерацию новых хешей в фоне.

### HashRepository  
- атомарное получение и удаление хешей;  
- работа с числовой последовательностью для генерации новых хешей.

### UrlRepository  
- атомарное удаление устаревших ссылок;  
- возврат освободившихся хешей.

### Base62Encoder  
Кодирует числовые значения в Base62 для получения компактных коротких ссылок.

### UrlCacheImpl  
Отвечает за кеширование оригинальной и сокращённой ссылок в Redis.
